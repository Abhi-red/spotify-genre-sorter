01

Pick a source playlist

Fetches every track and votes on each one's genre across Spotify, Last.fm, and MusicBrainz. Lookups are cached per artist/track, so a second run on the same playlist is much faster.

02

Genre breakdown

Dominant genre is a majority vote across each track's own detected tags -- never the playlist's own name, which is often a mood label rather than a genre.

02b

Review low-confidence matches

Only one source matched, or the sources disagreed. Assign a genre to sort a track, or leave it for later.

03

Map genres to target playlists

For each detected genre, choose a playlist to copy those tracks into, or leave as "Don't sort" to skip it.
